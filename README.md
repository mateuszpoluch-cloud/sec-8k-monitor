## Szkic ogrodu — Ekoos

Kod aktualnej aplikacji oraz pełna dokumentacja znajdują się na gałęzi **`gh-pages`** w katalogu `garden-sketch`.

Po sklonowaniu repozytorium w VS Code przełącz gałąź:

```bash
git switch gh-pages
```

Następnie otwórz:

- `garden-sketch/README.md`
- `garden-sketch/PROJECT_CONTEXT.md`
- `garden-sketch/CHANGELOG.md`
- `garden-sketch/AGENTS.md`
